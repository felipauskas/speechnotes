# Contributing to SpeechNotes

Contributions are welcome.

1. Open an issue or discussion for substantial changes before starting implementation.
2. Keep changes focused and explain the user-visible behavior they change.
3. Include tests or clear manual verification steps where practical.
4. Do not add secrets, recordings, transcripts, downloaded models, or other personal data to the repository.
5. Confirm that third-party code, models, and assets can be redistributed under their upstream terms.
6. Submit a pull request with a concise description and any relevant testing results.

By contributing, you agree that your contribution is licensed under the MIT License in this repository.
